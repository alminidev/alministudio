## 6. SEO Técnico Multilíngue

1. **Anotações Hreflang Cruzadas (Obrigatórias em ambas as páginas):**
   ```html
   <link rel="canonical" href="https://alministudio.com/pt/" />
   <link rel="alternate" hreflang="pt-BR" href="https://alministudio.com/pt/" />
   <link rel="alternate" hreflang="en" href="https://alministudio.com/en/" />
   <link rel="alternate" hreflang="x-default" href="https://alministudio.com/pt/" />
   ```
2. **Dados Estruturados (JSON-LD Schema.org):**  
   Implementar na seção `<head>` de `/pt` e `/en` o schema `ProfessionalService` para indexação rica no Google:
   ```json
   {
     "@context": "https://schema.org",
     "@type": "ProfessionalService",
     "name": "Almini Studio",
     "alternateName": "Almini Studio by Alexandre Polettini",
     "url": "https://alministudio.com/",
     "logo": "https://alministudio.com/assets/nix-logo.jpg",
     "description": "Estúdio independente de design digital, direção de arte e desenvolvimento front-end autoral.",
     "founder": {
       "@type": "Person",
       "name": "Alexandre Polettini",
       "jobTitle": "Front-End Developer & Designer"
     },
     "sameAs": [
       "https://github.com",
       "https://linkedin.com",
       "https://instagram.com",
       "https://behance.net"
     ]
   }
   ```
3. **Robots.txt & Sitemap:**
   * `robots.txt` autorizando indexação de `/pt/` e `/en/`.
   * `sitemap.xml` contendo ambas as versões com suas tags `xhtml:link` equivalentes.
4. **Performance & Core Web Vitals:**
   * HTML/CSS puro garante First Contentful Paint (FCP) e Largest Contentful Paint (LCP) em menos de 0.8s em conexões padrão.
   * Zero JavaScript bloqueador de renderização.

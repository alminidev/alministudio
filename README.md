## Sobre

Este repositório contém o site oficial do Almini Studio. O projeto apresenta os serviços do estúdio, os trabalhos selecionados e os canais de contato.

O estúdio nasce da combinação de mais de 25 anos de experiência em design gráfico e produção visual com desenvolvimento front-end.

## Serviços

- **Sites e landing pages:** layouts autorais, responsivos e pensados para conversão
- **Identidade visual:** logo, paleta, tipografia e aplicações da marca
- **Design para pequenas empresas:** materiais coerentes com o posicionamento de cada cliente

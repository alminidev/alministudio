# Escopo do Projeto — ALMINI STUDIO

## Itens Inclusos no Projeto
1. **Estrutura Multilíngue Completa:**
   - Versão Português Brasileiro (`/pt/index.html`).
   - Versão Internacional em Inglês (`/en/index.html`).
   - Roteador de entrada na raiz (`index.html`) com redirecionamento inteligente baseado em preferência salva e navegador.
2. **Design System & Componentes Almini Studio:**
   - Paleta de cores dark mode `#000000` de alto contraste.
   - Tipografia refinada (Display monumental, texto mono e corpo grotesco).
   - Componentes de navegação inspirados no template Amplify com seletor `[ PT | EN ]`.
3. **Seções de Conteúdo Estratégico:**
   - Header fixo com drawer menu suspenso.
   - Hero com headline monumental e CTAs duplos.
   - Seção de Manifesto autoral.
   - Seção de Selected Works com projetos (NIX, FRIGELAR, Autoral/Experimental).
   - Seção de Serviços (4 pilares).
   - Seção de Processo (4 etapas).
   - Seção About do estúdio.
   - Seção de Contato com ações funcionais.
   - Footer institucional completo.
4. **SEO Técnico Internacional:**
   - Meta tags específicas por idioma, links canônicos e tags `hreflang` cruzadas.

## Itens Fora do Escopo (Não Inclusos)
- Painel administrativo / CMS dinâmico.
- Banco de dados ou backend server-side.
- Sistema de e-commerce ou processamento de pagamentos.

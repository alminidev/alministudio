# Stack Lock — ALMINI STUDIO

## Permitido (Tecnologias Autorizadas)
- **HTML5:** Marcação semântica estrita (`header`, `main`, `section`, `article`, `nav`, `footer`).
- **CSS3:** Estilização pura utilizando CSS Custom Properties (variáveis), Flexbox, CSS Grid, `clamp()`, media queries nativas.
- **JavaScript:** ES6+ puro (Vanilla JS), sem dependências externas, bibliotecas ou frameworks.
- **Fontes Web:** Google Fonts carregadas via `<link>` (`Inter`, `Bebas Neue`, `IBM Plex Mono`, `IBM Plex Sans`).
- **Assets:** Imagens em formato PNG, SVG, JPG ou AVIF otimizadas.

## Proibido (Sem Exceções)
- React, Next.js, Vue, Nuxt, Angular, Svelte.
- Tailwind CSS, Bootstrap, Bulma, Sass/SCSS compiladores externos.
- jQuery ou bibliotecas DOM pesadas.
- Bibliotecas pesadas de animação (GSAP pago, Three.js complexo sem autorização prévia).
- Qualquer build tool (Webpack, Vite, Rollup) que impeça a execução direta no navegador.
